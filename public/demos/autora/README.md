# AUTORA

Власний демонстраційний проєкт DM Studio: сайт підбору та доставки авто зі США. Продовження початкової HTML/CSS/JS-реалізації автора.

## Реалізовано
- Адаптивна головна сторінка, оригінальний логотип і відео; спочатку відео, після завершення — плавна поетапна поява контенту й меню. Є пропуск вступу, reduced-motion та резервний показ при блокуванні або помилці відео.
- Каталог: пошук, фільтри статусу, сортування, обране (локальні налаштування браузера), деталі авто.
- Інтерактивний калькулятор з розкладкою витрат і валідацією параметрів.
- Режим посилання Copart/IAA: перевірка домену, додавання посилання до запиту. Автоматичного читання лота немає.
- Діалог підбору, сценарії використання, попередній перегляд та завантаження заявки.
- Клавіатурна навігація, native dialog, доступні стани, reduced-motion та резервне зображення відео.

## Межі демонстрації
Автомобілі, характеристики, статуси, ціни, логістика та коефіцієнти оформлення є ілюстративними. Калькулятор не використовує актуальні митні тарифи. Реальних лотів, перевірених VIN, клієнтських відгуків або виконаних доставок тут немає. Форма не відправляє персональні дані; її результат — локальний текстовий файл. Для комерційного запуску потрібні реальні дані, перевірені тарифи, серверна форма/CRM та власні контакти компанії.

## Запуск
Статичний сайт: віддати цю директорію через HTTP. Наприклад: `python3 -m http.server 8080`. Для тестів: `node --test tests/model.test.mjs`.
