# NFC Food AI — TikTok delivery

23 seconds, 1080×1920, 30 fps. H.264 video with original synthesized sound accents.

- `nfc-food-ai-complete.zip`: complete delivery (MP4, cover, Remotion source ZIP, caption).
- `nfc-food-ai-tiktok.mp4`: exported video.
- `cover.png`: 1080×1920 cover.
- `nfc-food-ai-source.zip`: source project and launch/export commands.
- `caption.txt`: Ukrainian caption and hashtags.

Download a file by opening it on GitHub and choosing **Download raw file**. For the whole branch, use **Code → Download ZIP**.

Real product screenshots and an actual successful API analysis were used. The food illustration is AI-generated and labeled. NFC is illustrated; the Telegram scene shows the actual product's bot-link button, without fabricating a conversation or claiming verified message delivery. Approximate nutrition is shown as an editorial visualization of the API response. Nothing was published to TikTok.
