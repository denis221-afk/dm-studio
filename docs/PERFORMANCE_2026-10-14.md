## Підтверджено HTTP-перевіркою

Railway вже стискає HTML, JS і CSS через gzip. До змін головний HTML передавався приблизно як 12.4 KB, CSS — 38.6 KB, JS — 52.3 KB; точні значення залежать від стиснення на сервері. Ресурси демо без хешу, зокрема /demos/modera/assets/style.css, отримували річний immutable-кеш. Це могло залишати застарілі стилі після оновлення.

## Зміни

- Річний immutable-кеш лишився для ресурсів Vite з хешем в імені. Демо, HTML та інші змінювані ресурси використовують no-cache (можна зберігати, але перед повторним використанням перевіряється актуальність).
- Додано ETag і Last-Modified; If-None-Match дозволяє повернути 304 без тіла, якщо файл не змінено.
- Manrope обмежено латиницею, розширеною латиницею, кирилицею та розширеною кирилицею, з unicode-range. Збережено українські літери, польські знаки й гривню. Використовуються WOFF2; зайві грецькі, в’єтнамські та WOFF-ресурси вилучено зі збірки. Це зменшує пакет ресурсів, але не доводить покращення LCP/INP.
- Візуальний дизайн і тривалість заставки не змінювалися без вимірювання її впливу.

Лабораторний звіт: Performance 70; Accessibility/Best Practices/SEO 100; FCP 3.2 s, LCP 4.6 s, TBT 90 ms, CLS 0.099, Speed Index 5.8 s. Це не польова оцінка INP або підтвердження Core Web Vitals. Прицільні зміни:

- Портрет 817×1472, близько 240 KB: додано варіанти 320/480/640/817w — 29.7/52.7/83.0/107.9 KB. Srcset і sizes у зображенні та preload збігаються. Початковий оригінал збережено.
- Повний текст статті й дані сторінок послуг вилучено з початкового клієнтського JS. Компактні метадані статті автоматично генеруються під час збірки; статичні статті й переклади збережено. Основний JS: 158 511 → 131 225 байтів без стиснення; новий локальний gzip — 42 612 байтів. Ці зміни не означають, що весь flagged unused JS вилучено: частина належить зовнішній аналітиці та відкладеним сценаріям.
- Стилі першого екрана головних UA/EN/PL сторінок вбудовано в HTML. Решта stylesheet завантажується неблокувально з noscript-fallback. Критичний CSS генерується з тих самих зібраних правил; локальний gzip приблизно 16.3 KB. HTML головної зі стилями — приблизно 29.0 KB gzip. На інших сторінках звичайне завантаження CSS збережено.
- Переліт іконок використовує translate/scale замість зміни left/top/width/height на кожному кадрі. Цільові координати рахуються за фактичним прямокутником іконки; тривалість і завершальний показ тексту збережено.
