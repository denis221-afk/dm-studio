## Межі сторінок і внутрішні посилання

- `/services/wordpress-elementor/` — головна для змін на існуючому WP/Elementor-сайті. Не перетворювати її на сторінку всіх IT-послуг.
- `/services/web-development/` — новий сайт/лендінг з нуля. Не забирати на неї основну тему правок Elementor.
- `/services/business-automation/` — передавання/обробка заявки, інтеграція з Telegram/таблицями/API. Візуальна форма залишається підтемою WP-сторінки; інтеграційна сторінка описує доставку та процес.
- `/services/telegram-bots/` — окремий бот зі своїми сценаріями, а не будь-яка форма з Telegram-сповіщенням. Докладне ядро — етап 4.
- `/cases/rhome-ohio/` — підтвердження виконаних WordPress/Elementor-правок; не конкуруюча копія посадкової. Додавати конкретні роботи, а не дублювати комерційний текст.
- `/cases/serviceflow/` — явно власний проєкт; не називати оплаченим клієнтським кейсом.
- Головна та `/services/` — огляд, короткі описи й посилання на спеціалізовану посадкову.

## Завдання для етапу 6 (ще не застосовано)

1. Кандидат H1: «Доопрацювання сайту на WordPress та Elementor».
2. Кандидат title: «Доопрацювання WordPress та Elementor — правки сайту | DM Studio». Не перелічувати всі 20 варіантів у title.
3. Кандидат description: «Доопрацювання готового сайту на WordPress та Elementor: мобільна версія, блоки, стилі, контент і форми. Перегляньте кейс і надішліть список правок.»
4. Зробити 3–4 корисні блоки: адаптив; стилі/блоки; контент; форма. Для кожного — приклад проблеми та критерій готовності, не повтор ключових слів.
5. Уточнити вартість/термін через фактори: кількість сторінок, список проблем, доступи, готовність матеріалів, платні плагіни. Не вигадувати мінімальний чек або фіксовані години.
6. CTA: «Надішліть посилання на сайт і список правок». Пояснити, що спочатку узгоджується обсяг.
7. Доказ: RHome Ohio саме для контенту/стилів/адаптиву. ServiceFlow — власна демонстрація. Не обіцяти зростання конверсії або конкретних PageSpeed-балів.
8. Після редагування зберегти uk/en/pl, canonical/hreflang, schema та перевірити внутрішні посилання. Переклад тексту не є дослідженням EN/PL ключів.

- «Створення сайту WordPress під ключ» → інша послуга, не ядро цієї сторінки.
- Злам/видалення вірусів, складні PHP-плагіни, цілодобова підтримка, VPS-адміністрування → не залучати обіцянками без відповідного підтвердженого досвіду та обсягу.
- «Прискорення Elementor до 100 балів» → не обіцяти. Оптимізація швидкості лише після аудиту й перевірки доказів; результати Vite-сайту DM Studio не видавати за WordPress-кейс.
- Запити «безкоштовно», «скачати», «nulled», «курс», «урок», «вакансія» → не цільові для посадкової послуги.
- Не створювати міські сторінки з неіснуючими офісами; дистанційна робота по Україні не означає офіс у кожному місті.
