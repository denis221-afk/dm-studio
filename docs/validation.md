# Перевірки готового проєкту

- npm run check: переклади, одна h1, цілісність елементів при локалізації, JSON-LD, canonical/hreflang із тестовим доменом, відсутність дубльованих ID, якірні посилання, символи SVG.
- npm run build: успішна production-збірка та статичний HTML для UA/EN/PL.
- Chromium: перевірено українську, англійську й польську версії.
- Ширини: 320, 375, 768, 1024, 1280, 1440, 1672, 1920 px. Горизонтального переповнення немає.
- Помилок JavaScript і невдалих HTTP-запитів у цих перевірках немає.
- Заставка видаляється з DOM після завершення; reduced-motion пропускає її; без JavaScript вона прихована.
- Контент англійської версії існує у статичному HTML без JavaScript.
- Мобільне меню відкривається кнопкою і закривається Escape.
- Перемикання мов переходить на правильні маршрути.
- Копіювання брифу працює і показує повідомлення про результат.
- axe-core: 0 автоматично виявлених порушень WCAG 2 A/AA та 2.1 AA у перевірених мобільних станах трьох мов.

Автоматичний аудит не є повною сертифікацією доступності. Візуально переглянуто desktop 1672×941 та mobile 375×812. Прев’ю англійське, відповідно до макета.
