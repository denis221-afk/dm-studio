# SEO-аудит DM Studio — 14 жовтня 2026

Сайт: https://dm-studio-production.up.railway.app/

## Підтверджений стан

Перевірено 36 індексованих HTML-сторінок: українська, англійська та польська головні сторінки, кейси, профіль, блог і політика конфіденційності. Сайт генерує HTML під час збірки, тому основний текст доступний пошуковим роботам без виконання JavaScript. Головні та вибрані внутрішні сторінки на чинному сайті відповідали HTTP 200. Неіснуюча адреса відповідала 404.

До аудиту вже були sitemap.xml, robots.txt, canonical, hreflang, локалізовані title/description, Open Graph, BreadcrumbList, ProfilePage і BlogPosting. Це допрацювання наявного SEO, а не встановлення з нуля.

## Внесені зміни

- Sitemap містить взаємні uk/en/pl/x-default зв'язки для всіх 36 сторінок. Демонстрації не включені. Дати останньої зміни не вигадані.
- Генерація canonical, sitemap та hreflang не пропускається, якщо SITE_URL відсутній: використовує Railway public domain або чинну адресу DM Studio. SITE_URL зберігає пріоритет для перенесення на інший домен.
- Постійні 308 перенаправлення /ua/ і явних index.html на основні адреси зі збереженням параметрів запиту. Відсутні сторінки залишаються 404.
- Robots.txt виключає технічні /api/ та /health і вказує sitemap.
- Заголовок X-Robots-Tag: noindex, follow додатково захищає /demos/. Не блокуємо демо через robots.txt, щоб робот міг прочитати noindex.
- Дозволені великі прев'ю зображень, повні текстові й відеофрагменти у результатах пошуку.
- Organization доповнено стабільним ID, контактною адресою, наявною іконкою та підтвердженими GitHub/Telegram-посиланнями. Головні сторінки мають WebSite, пов'язаний з Organization. Адреса офісу, рейтинги та відгуки не вигадані.
- Стаття має власне зображення Open Graph/Twitter замість загального прев'ю та фактичну дату публікації в article:published_time.
- Повторне renderHtml не накопичує canonical/hreflang іншої сторінки.
- Додано scripts/check-seo.mjs для перевірки зібраних сторінок і поведінки сервера.

## Перевірки

npm run check; npm run build; node scripts/check-seo.mjs; node --test server/validation.test.mjs — пройшли.

Перевірено: один H1 на сторінку, один правильний canonical, непорожній description, унікальні title в межах кожної мови, коректний JSON-LD, взаємні hreflang у HTML та XML, доступність зображень, внутрішні посилання, sitemap, перенаправлення і 404. В HTML індексованих сторінок не виявлено зображень без alt. Це структурна перевірка; якість кожного alt потребує редакційної оцінки.

## Що ще потребує доступу або окремої роботи

1. Google Search Console: власність, фактична індексація, обрані Google canonical, помилки сканування, запити та покази ще не перевірені. GA4 не замінює Search Console. Потрібне підключення ресурсу і подання /sitemap.xml; встановлений Google tag у head може використовуватись для відповідного методу підтвердження, але успішну перевірку власності не підтверджено.
2. Core Web Vitals: немає результатів вимірювання LCP/INP/CLS або польової статистики. Довга заставка — кандидат на перевірку впливу на перший показ контенту; дизайн у цьому SEO-оновленні не змінювався. Збірка: CSS приблизно 37 KB gzip, JS приблизно 47 KB gzip; ці розміри не є оцінкою швидкості.
3. Контентне SEO: послуги зараз переважно секції головної. Наступний змістовний етап — окремі сторінки розробки сайтів, WordPress/Elementor, Telegram-ботів і автоматизацій із реальними кейсами, обсягом роботи й відповідями на питання клієнтів. Не створювати масові однакові сторінки міст.
4. Позиції та потрапляння в індекс залежать від Google. Технічні налаштування не є гарантією рейтингу чи трафіку.
