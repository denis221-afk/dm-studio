# DM Studio

Готова адаптивна сторінка на HTML, CSS і JavaScript у вашій архітектурі Vite.

## Запуск

Потрібен Node.js 22.12+ або 24 LTS.

```bash
npm ci
npm run dev
```

Vite покаже адресу локального сервера. Не відкривайте index.html через file://.

```bash
npm run check
npm run build
npm run preview
```

Готова статична версія також уже є в `dist/`. Її можна розмістити на статичному хостингу без встановлення Node.js на сервері.

## Структура

- `index.html` — повний український HTML: навігація, hero, картки послуг, кейс, контактний бриф і SEO.
- `src/main.js` — підключення стилів та ініціалізація модулів.
- `src/style.css` — єдина точка імпорту стилів і локального Manrope.
- `src/styles/variables.css` — кольори та шрифтові токени.
- `src/styles/global.css` — базові стилі, кнопки, фокус, skip-link.
- `src/styles/page.css` — композиція сторінки та адаптивність.
- `src/styles/Loader.css` — заставка з масштабуванням логотипа та світловими смугами.
- `src/js/loader.js` — заставка з обмеженням тривалості та видаленням із DOM.
- `src/js/navigation.js` — доступне мобільне меню.
- `src/js/brief.js` — копіювання опису задачі.
- `src/i18n/ua.js`, `en.js`, `pl.js`, `index.js` — переклади й мовні маршрути.
- `src/assets/2.png` — ваш оригінальний портрет.
- `public/images/` — оптимізований портрет WebP, аватари та мініатюра кейсу.
- `public/icons.svg` — локальний SVG-спрайт із сервісними іконками.
- `scripts/prerender.mjs` — статичний HTML для мовних версій.
- `scripts/check.mjs` — перевірка перекладів, структури HTML, посилань, іконок та метаданих.

## Мови

- `/` — українська.
- `/ua/` — сумісний український маршрут із вашого проєкту.
- `/en/` — англійська, найближча за текстом до макета.
- `/pl/` — польська.

У production кожна версія має власний повний HTML із перекладеним текстом і метаданими. У режимі розробки Vite використовує HTML fallback і застосовує переклади в браузері.

## Домен та SEO

Задайте справжній домен під час збірки:

```bash
SITE_URL=https://your-real-domain.com npm run build
```

Замініть приклад на ваш домен. Тоді збірка додасть canonical, og:url, hreflang, абсолютне social preview, sitemap.xml та адресу sitemap у robots.txt. Без домену сайт збирається, але ці адресні поля не вигадуються.

Український `/ua/` canonical веде на `/`, щоб уникнути дублювання. Контент існує без JavaScript; є одна h1, семантичні landmarks, опис послуг, Organization JSON-LD без фіктивних рейтингів, локальні зображення та шрифти. Це забезпечує зрозумілу основу для пошуку й AI-систем; позиції або рекомендації не гарантуються.

## Перед публікацією

Контактний блок чесно копіює бриф. Він не надсилає заявку: замініть його реальними контактами або підключіть API у `src/js/brief.js`. Реальні email, Telegram та домен не були надані.

Показники — 2 виконані проєкти та 2 відгуки, відповідно до наданого контексту. «10+ happy clients» із макета не використано як непідтверджене твердження. Автогенеровані аватари з макета — декоративні, не фотографії підтверджених клієнтів; alt порожній. За бажанням замініть блок своїми матеріалами.

Мініатюра Restaurant NFC Menu та аватари вирізані з макета. Портрет використовує ваш оригінал із прозорістю. Опис кейсу позначає його як концепт, без вигаданих результатів.

## Заставка та доступність

Заставка прихована в початковому HTML; при помилці JavaScript вона не перекриває сайт. Показується один раз за сесію та видаляється з DOM максимум за 3.3 секунди. Не залежить від window.load. Є кнопка пропуску; клавіша та перехід фокусу до сайту також закривають її. Reduced-motion пропускає заставку. Для повторного перегляду відкрийте нову приватну сесію.

Мобільне меню працює з клавіатури, має aria-expanded і закривається через Escape. Форми мають label і live-status. Кольори допоміжного тексту затемнені для контрастності, тому можуть трохи відрізнятися від растрового макета.
